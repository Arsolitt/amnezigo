## 1. Goal and Scope

Ship a single `lib/presets.libsonnet` file that users import in their `.amnezigo.jsonnet` manifests to compose obfuscation profiles from curated baselines.

**Core idea**: presets are standalone jsonnet objects. The manifest schema has NO preset name field — the manifest only carries explicit obfuscation values. Users who want presets import them in jsonnet, pick/merge/override, and the resulting manifest already has resolved values. The Go pipeline never sees preset names; it only sees concrete S/H/J parameters.

**What this PR delivers**:

- `lib/presets.libsonnet` — a manually maintained jsonnet library exporting all four built-in presets as objects.
- Default jpath adjustment — ensure the loader's default `--jpath` includes the directory containing `presets.libsonnet` so that `import 'presets.libsonnet'` resolves without extra configuration.
- Tests — validate that the libsonnet file evaluates correctly and its field values match the Go preset registry in `presets.go`.

**What stays unchanged**:

- `presets.go` and its registry — used by legacy `validate` and `analyze` commands (P1.5 path). NOT used by the manifest pipeline.
- The manifest schema (`ObfuscationManifest`) — no `preset` field is added. The manifest carries only explicit S/H/J values.
- The pipeline (`pipeline.go` from P2.4) — no `resolveObfuscation()` function. If a user writes obfuscation values inline, the pipeline uses them directly. If they import a preset in jsonnet, the jsonnet VM resolves it before the Go code sees the JSON.

**Out of scope**:

- Code generation from Go to jsonnet — the libsonnet file is manually maintained. A sync test catches drift.
- Embedding libsonnet in the binary — the file lives on disk for the jsonnet VM's `FileImporter`.
- Community presets as libsonnet — community presets are YAML in `presets/` (P1.5). Only built-in presets get jsonnet library exposure.
- Per-preset separate files — one `presets.libsonnet` file exports all presets as a single library object.

## 3. Usage Examples

### Full preset (no overrides)

```jsonnet
local presets = import 'presets.libsonnet';

{
  version: 1,
  network: {
    dns: ['1.1.1.1', '8.8.8.8'],
  },
  obfuscation: presets.homeBalanced,
  peers: {
    server: {
      address: '10.0.0.1/24',
      endpoint: 'vpn.example.com:51820',
      listen_port: 51820,
    },
    phone: {
      address: '10.0.0.2/32',
    },
  },
}
```

### Preset with field overrides

```jsonnet
local presets = import 'presets.libsonnet';
local mobile = presets.mobileAggressive;

{
  version: 1,
  obfuscation: mobile + { s1: 80, protocol: 'quic' },
  peers: {
    server: {
      address: '10.0.0.1/24',
      endpoint: 'vpn.example.com:51820',
      listen_port: 51820,
    },
    phone: {
      address: '10.0.0.2/32',
    },
  },
}
```

### Different presets for different peers (advanced)

Note: in AWG 2.0, S/H/J parameters must be identical across all peers (server-wide). The `protocol` field can vary per-peer. This example shows per-peer protocol override:

```jsonnet
local presets = import 'presets.libsonnet';

{
  version: 1,
  obfuscation: presets.homeBalanced,
  peers: {
    server: {
      address: '10.0.0.1/24',
      endpoint: 'vpn.example.com:51820',
      listen_port: 51820,
    },
    phone: {
      address: '10.0.0.2/32',
      protocol: 'dns',
    },
    laptop: {
      address: '10.0.0.3/32',
      protocol: 'quic',
    },
  },
}
```

### Merging fields from different presets

```jsonnet
local presets = import 'presets.libsonnet';

{
  version: 1,
  // Take S values from mobile, junk params from home, H ranges from lan
  obfuscation: {
    s1: presets.mobileAggressive.s1,
    s2: presets.mobileAggressive.s2,
    s3: presets.mobileAggressive.s3,
    s4: presets.mobileAggressive.s4,
    h1: presets.lanConservative.h1,
    h2: presets.lanConservative.h2,
```

## 4. How Preset Values Map to Manifest Schema Fields

The manifest schema (`ObfuscationManifest` from P2.1) uses these fields:

| Manifest field | Preset source (Go) | Type | Notes |
| --- | --- | --- | --- |
| `s1` | `Preset.S1` | int | Padding for initiation message |
| `s2` | `Preset.S2` | int | Padding for response message |
| `s3` | `Preset.S3` | int | Padding for cookie reply |
| `s4` | `Preset.S4` | int | Padding for transport |
| `h1` | `Preset.H1` | `{ min, max }` | Header range 1; uint32 in Go, number in jsonnet |
| `h2` | `Preset.H2` | `{ min, max }` | Header range 2 |
| `h3` | `Preset.H3` | `{ min, max }` | Header range 3 |
| `h4` | `Preset.H4` | `{ min, max }` | Header range 4 |
| `jc` | `Preset.Jc` | int | Junk packet count |
| `jmin` | `Preset.Jmin` | int | Minimum junk size |
| `jmax` | `Preset.Jmax` | int | Maximum junk size |
| `protocol` | `Preset.DefaultProtocol` | string | I-packet protocol: quic, dns, dtls, stun, sip, random |

**Not in the libsonnet file** (Go-only metadata):

- `Preset.Name` — the jsonnet field name (`homeBalanced`) replaces this.
- `Preset.Description` — rendered as a comment above each preset object.
- `Preset.MTU` — MTU is a network-level setting in the manifest schema (`NetworkConfig.MTU`), not part of the obfuscation section. The Go preset includes it for backward compatibility with the legacy `init --preset` path, but it does not belong in the jsonnet obfuscation object.

**Preset name mapping** (Go kebab-case to jsonnet camelCase):

| Go name | Jsonnet field | Description |
| --- | --- | --- |
| `lan-conservative` | `lanConservative` | Corporate LANs, minimal DPI |
| `home-balanced` | `homeBalanced` | Home internet, moderate DPI |
| `mobile-aggressive` | `mobileAggressive` | Carrier networks, heavy DPI |
| `test-minimal` | `testMinimal` | CI and integration testing |

**Header range precision**: Go uses `uint32` for `HeaderRange.Min/Max`. Jsonnet numbers are IEEE 754 doubles, which exactly represent all integers up to 2^53. Max uint32 (4,294,967,295) is well within range — no precision loss.

## 5. Installation and Distribution

### File location

```
lib/presets.libsonnet
```

The file lives at the repository root under `lib/`. This matches the default `--jpath` convention established by P2.2: the loader defaults `jpathDirs` to `[]string{filepath.Join(dir, "lib")}` where `dir` is the manifest's parent directory.

### Import resolution

When a user writes `import 'presets.libsonnet'` in their `.amnezigo.jsonnet`, the jsonnet VM's `FileImporter` searches the jpath directories. With the default jpath of `<manifest-dir>/lib/`, the import resolves to `<manifest-dir>/lib/presets.libsonnet`.

No additional `--jpath` configuration needed for co-located manifests:

```
project/
  .amnezigo.jsonnet      # import 'presets.libsonnet' works by default
  lib/
    presets.libsonnet
```

### Bundled with binary distribution

For single-binary distributions (future), two options exist:

1. **Ship the file alongside the binary** — include `lib/presets.libsonnet` in the release archive. Users place it relative to their manifest.
2. **Embed and extract** — use `go:embed` to bundle the file, extract to a temp dir at runtime, add to jpath. This is deferred; the on-disk approach works for all current distribution methods (package managers, release archives, `go install`).

### Standalone installation

Users who want the presets library without cloning the repo:

```bash
mkdir -p lib
curl -o lib/presets.libsonnet https://raw.githubusercontent.com/Arsolitt/amnezigo/main/lib/presets.libsonnet
```

### Step 7.3 — Write sync test

Create `presets_jsonnet_test.go` to verify the libsonnet file stays in sync with the Go registry:

```go
package amnezigo

import (
    "encoding/json"
    "os"
    "path/filepath"
    "testing"

    jsonnet "github.com/google/go-jsonnet"
)

// TestPresetsLibsonnetSync verifies that lib/presets.libsonnet evaluates to
// objects that match the Go presetRegistry field-by-field.
func TestPresetsLibsonnetSync(t *testing.T) {
    data, err := os.ReadFile(filepath.Join("lib", "presets.libsonnet"))
    if err != nil {
        t.Fatalf("read lib/presets.libsonnet: %v", err)
    }

    vm := jsonnet.MakeVM()
    jsonStr, err := vm.EvaluateAnonymousSnippet("presets.libsonnet", string(data))
    if err != nil {
        t.Fatalf("evaluate presets.libsonnet: %v", err)
    }

    var lib map[string]any
    if err := json.Unmarshal([]byte(jsonStr), &lib); err != nil {
        t.Fatalf("unmarshal presets.libsonnet output: %v", err)
    }

    // Mapping from Go preset names to jsonnet field names
    nameMap := map[string]string{
        "lan-conservative":  "lanConservative",
        "home-balanced":     "homeBalanced",
        "mobile-aggressive": "mobileAggressive",
        "test-minimal":      "testMinimal",
    }

    for _, p := range ListPresets() {
        jsonnetName, ok := nameMap[p.Name]
        if !ok {
            t.Fatalf("no jsonnet name mapping for preset %q", p.Name)
        }

        t.Run(p.Name, func(t *testing.T) {
            obj, ok := lib[jsonnetName].(map[string]any)
            if !ok {
                t.Fatalf("preset %q not found or not an object in libsonnet", jsonnetName)
            }

            // Assert scalar fields
            assertIntField(t, obj, "s1", p.S1)
            assertIntField(t, obj, "s2", p.S2)
            assertIntField(t, obj, "s3", p.S3)
            assertIntField(t, obj, "s4", p.S4)
            assertIntField(t, obj, "jc", p.Jc)
            assertIntField(t, obj, "jmin", p.Jmin)
            assertIntField(t, obj, "jmax", p.Jmax)
            assertStringField(t, obj, "protocol", p.DefaultProtocol)

            // Assert header ranges
            assertHeaderRange(t, obj, "h1", p.H1)
            assertHeaderRange(t, obj, "h2", p.H2)
            assertHeaderRange(t, obj, "h3", p.H3)
            assertHeaderRange(t, obj, "h4", p.H4)
        })
    }
}

// TestPresetsLibsonnetEval verifies the file evaluates to valid jsonnet
// and contains exactly the four expected preset keys.
func TestPresetsLibsonnetEval(t *testing.T) {
    data, err := os.ReadFile(filepath.Join("lib", "presets.libsonnet"))
    if err != nil {
        t.Fatalf("read lib/presets.libsonnet: %v", err)
    }

    vm := jsonnet.MakeVM()
    jsonStr, err := vm.EvaluateAnonymousSnippet("presets.libsonnet", string(data))
    if err != nil {
        t.Fatalf("evaluate presets.libsonnet: %v", err)
    }

    var lib map[string]any
    if err := json.Unmarshal([]byte(jsonStr), &lib); err != nil {
        t.Fatalf("unmarshal: %v", err)
    }

    expected := []string{"lanConservative", "homeBalanced", "mobileAggressive", "testMinimal"}
    for _, name := range expected {
        if _, ok := lib[name]; !ok {
            t.Errorf("missing preset %q in libsonnet output", name)
        }
    }
    if len(lib) != len(expected) {
        t.Errorf("expected %d presets, got %d", len(expected), len(lib))
    }
}

// TestPresetsLibsonnetNoExtraKeysInLibsonnet verifies the reverse direction:
// if a key exists in the libsonnet output but NOT in the Go presetRegistry,
// the test fails. This catches stale or manually added presets in libsonnet
// that have no Go counterpart.
func TestPresetsLibsonnetNoExtraKeysInLibsonnet(t *testing.T) {
    data, err := os.ReadFile(filepath.Join("lib", "presets.libsonnet"))
    if err != nil {
        t.Fatalf("read lib/presets.libsonnet: %v", err)
    }

    vm := jsonnet.MakeVM()
    jsonStr, err := vm.EvaluateAnonymousSnippet("presets.libsonnet", string(data))
    if err != nil {
        t.Fatalf("evaluate presets.libsonnet: %v", err)
    }

    var lib map[string]any
    if err := json.Unmarshal([]byte(jsonStr), &lib); err != nil {
        t.Fatalf("unmarshal presets.libsonnet output: %v", err)
    }

    // Build set of valid jsonnet names from Go registry
    validJsonnetNames := make(map[string]bool)
    nameMap := map[string]string{
        "lan-conservative":  "lanConservative",
        "home-balanced":     "homeBalanced",
        "mobile-aggressive": "mobileAggressive",
        "test-minimal":      "testMinimal",
    }
    for _, p := range ListPresets() {
        jsonnetName, ok := nameMap[p.Name]
        if !ok {
            t.Fatalf("no jsonnet name mapping for preset %q", p.Name)
        }
        validJsonnetNames[jsonnetName] = true
    }

    for key := range lib {
        if !validJsonnetNames[key] {
            t.Errorf("libsonnet contains preset %q which has no matching Go preset in presetRegistry", key)
        }
    }
}

// TestPresetsLibsonnetNoMissingPresets verifies that if a new preset is added
// to the Go presetRegistry without updating the libsonnet file, the test fails.
// This is the forward direction: Go is the source of truth, libsonnet must keep up.
func TestPresetsLibsonnetNoMissingPresets(t *testing.T) {
    data, err := os.ReadFile(filepath.Join("lib", "presets.libsonnet"))
    if err != nil {
        t.Fatalf("read lib/presets.libsonnet: %v", err)
    }

    }

    var lib map[string]any
    if err := json.Unmarshal([]byte(jsonStr), &lib); err != nil {
        t.Fatalf("unmarshal presets.libsonnet output: %v", err)
    }

    nameMap := map[string]string{
        "lan-conservative":  "lanConservative",
        "home-balanced":     "homeBalanced",
        "mobile-aggressive": "mobileAggressive",
        "test-minimal":      "testMinimal",

        if !ok {
            t.Fatalf("no jsonnet name mapping for preset %q", p.Name)
        }
        if _, found := lib[jsonnetName]; !found {
            t.Errorf("Go preset %q (jsonnet name %q) has no matching entry in libsonnet — add it to lib/presets.libsonnet", p.Name, jsonnetName)
        }
    }
}
```

## 11. Risks and Edge Cases

| Risk | Mitigation |
| --- | --- |
| **Libsonnet drift** — `presets.go` is edited but `presets.libsonnet` is not updated | `TestPresetsLibsonnetSync` fails in CI with a clear message naming the mismatched field. `TestPresetsLibsonnetNoMissingPresets` catches new Go presets missing from libsonnet. |
| **Jsonnet field name mismatch** — libsonnet uses `homeBalanced` but user expects `home-balanced` | camelCase is standard jsonnet convention; documented in section 4 mapping table. |
| **Header range precision loss** — uint32 values in jsonnet doubles | IEEE 754 doubles exactly represent all integers up to 2^53. Max uint32 (~4.3 billion) is safe. |
| **MTU not in libsonnet** — users expect MTU in the preset object | MTU is a network-level setting (`NetworkConfig.MTU`), not obfuscation. Documented in section 4. |
| **Missing libsonnet file** — user imports presets but file is not on disk | jsonnet VM produces clear import-resolution error with the expected file path. |
| **User imports presets in JSON manifest** — `import` only works in jsonnet | JSON manifests must specify obfuscation fields explicitly. Preset import is a jsonnet-only feature. |
